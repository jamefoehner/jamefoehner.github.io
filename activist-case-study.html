01 / The question

Which companies deserve a closer look?

Activist research involves two connected questions: which companies might attract activist interest, and what an investor actually wants after filing a position. I built a model to prioritize companies for research and a separate tool to extract demands from new Schedule 13D filings.

02 / The build

A workflow from source data to application.

I collected 232 campaigns from SEC filings and joined them to WRDS financial and return data. The event study matched 227 campaigns to price data; 225 had complete returns for the diffusion study.

The predictive screener uses roughly 44,000 company-years of peer-relative Compustat data. Walk-forward evaluation covers 2016–2025, with a one-year gap between training and testing so the model only uses information available at the time.

Post Holdings ranked seventh among 2,606 U.S. companies in the current screen. I used it for a deeper investment case, building an Excel model that compares debt-funded buybacks with selling Weetabix and paying down debt.

The live Streamlit app completes the workflow: it retrieves filings, extracts Item 4, and uses Claude to classify ten demand categories. Users can search roughly 2,600 companies and inspect scores, campaign histories, and source text alongside each label.

04 / Revising the thesis

The evidence changed the pitch.

I tested whether reducing debt would support a valuation re-rating and whether separating businesses would unlock value. Post’s historical valuation and a study of 182 spin-offs did not support those assumptions strongly enough to include them in the core case.

The final model makes the trade-off explicit: the plan sacrifices some base-case value for better downside protection. A Foodservice spin-off remains an illustrative option.

05 / A model failure

High accuracy can hide a bad answer.

In a follow-up study, I fine-tuned Qwen2.5-1.5B with LoRA and implemented GRPO reinforcement learning. Optimizing plain field accuracy from the base model led to all-zero answers on 66 of 89 filings, despite reporting 87% accuracy.

A stricter set-overlap reward also collapsed, this time to one-label answers. Starting from the fine-tuned model avoided collapse. The best run reached 0.73 macro-F1, but the difference from fine-tuning alone was not statistically distinguishable in paired bootstrap tests.

06 / Limits & lessons

What I would be careful about.

The monitor was tested on 89 original 13Ds, while live filings are often amendments. Governance and capital discipline are weaker categories, and labels should be reviewed against the filing text.

The RL experiments use single runs and a small test set. They demonstrate failure modes rather than how often those failures occur. Investment outcomes depend on model assumptions, and the screener covers only the activists and filings included in the research.

This project brought the full process together: data collection, predictive modeling, language-model evaluation, deployment, and revising an argument when the evidence did not support it.
